# FiberModeler — установка и запуск

Полная инструкция: Windows, macOS, Linux. Через терминал и без терминала.

</div>

---

## Коротко

| Что у вас | Что делать |
|---|---|
| Просто хочу открыть и работать | Скачать `dist/FiberModeler.html` и открыть двойным кликом. Больше ничего не нужно |
| Windows, без терминала | Распаковать архив → двойной клик по `FiberModeler.bat` |
| macOS, без терминала | Распаковать архив → двойной клик по `FiberModeler.command` |
| Любая система, через терминал | `python3 serve.py` в папке проекта |

Устанавливать нечего: у программы **нет зависимостей**, она не ходит в сеть и не требует аккаунта.
Локальный сервер нужен только потому, что браузеры не дают ES-модулям работать с `file://` —
в варианте «один файл» он не нужен вовсе.

---

## Вариант 1. Один файл — без установки вообще

Самый простой способ. Работает на Windows, macOS и Linux одинаково.

1. Возьмите файл `dist/FiberModeler.html` (из архива или из репозитория).
2. Положите куда угодно — хоть на рабочий стол, хоть на флешку.
3. Откройте двойным кликом.

Всё приложение — один HTML-файл на ~935 КБ: редактор, обе нотации, экспорт в PDF со встроенным
шрифтом, библиотека процессов WEG. Интернет не нужен, Python не нужен, права администратора не нужны.

> Ограничение одно: в режиме `file://` браузер не разрешает автосохранение в IndexedDB в некоторых
> конфигурациях приватного режима. Проекты всё равно сохраняются вручную в `.fibermodel`
> (**Файл → Сохранить**). Если нужна полная работа с автосохранением — варианты 2–4.

## Вариант 2. Windows

### 2.1. Что нужно установить

**Python 3** — один раз, пять минут.

1. Откройте https://www.python.org/downloads/windows/
2. Скачайте «Windows installer (64-bit)» последней версии 3.x.
3. Запустите. **Обязательно поставьте галочку «Add python.exe to PATH»** на первом экране.
4. Нажмите «Install Now».

Проверить, что встал:

```cmd
py -V
```

Должно напечатать что-то вроде `Python 3.12.4`.

> Если команда `py` не найдена, попробуйте `python -V`. Если и её нет — вы пропустили галочку
> «Add python.exe to PATH»: запустите установщик снова, выберите «Modify» и включите её.

Если нужен **Git** (для варианта «склонировать репозиторий») — https://git-scm.com/download/win,
установка со всеми настройками по умолчанию.

### 2.2. Запуск без терминала

1. Распакуйте архив `FiberModeler-1.1-WEG.zip` (правый клик → «Извлечь всё…»).
2. Войдите в папку `FiberModeler`.
3. Двойной клик по **`FiberModeler.bat`**.

Откроется чёрное окно консоли (это сервер — его не закрывайте) и следом браузер
на `http://127.0.0.1:8765`. Закончили работу — закройте окно консоли или нажмите в нём `Ctrl+C`.

> **SmartScreen** может сказать «Windows защитила ваш компьютер». Это нормально для неподписанного
> `.bat`: нажмите «Подробнее» → «Выполнить в любом случае».

### 2.3. Запуск через терминал (cmd или PowerShell)

Откройте «Командную строку» или PowerShell и выполните:

```cmd
cd %USERPROFILE%\Downloads\FiberModeler
py serve.py
```

Или, если склонировать с GitHub:

```cmd
cd %USERPROFILE%\Documents
git clone https://github.com/NeoBlau/FiberModeler.git
cd FiberModeler
py serve.py
```

Остановить — `Ctrl+C`.

Дополнительные ключи:

```cmd
py serve.py --port 9000        rem другой порт, если 8765 занят
py serve.py --no-open          rem не открывать браузер автоматически
py serve.py --host 0.0.0.0     rem пустить коллег по локальной сети
```

### 2.4. Ярлык на рабочий стол

Правый клик по `FiberModeler.bat` → «Отправить» → «Рабочий стол (создать ярлык)».
Дальше запускается в один клик.

## Вариант 3. macOS

### 3.1. Что нужно

Ничего. Python 3 в macOS есть из коробки. Проверить:

```bash
python3 -V
```

> Если macOS предложит установить «инструменты командной строки разработчика» — согласитесь,
> это штатный пакет Apple, он поставит и `python3`, и `git`.

### 3.2. Запуск без терминала

1. Распакуйте `FiberModeler-1.1-WEG.zip` (двойной клик).
2. Откройте папку `FiberModeler`.
3. Двойной клик по **`FiberModeler.command`**.

Если файл не запускается — один раз выдайте ему право на исполнение:

```bash
cd ~/Downloads/FiberModeler
chmod +x FiberModeler.command
```

> Если macOS скажет «не удаётся проверить разработчика»: правый клик по файлу → **Открыть** →
> в диалоге ещё раз **Открыть**. Нужно только в первый раз.

### 3.3. Запуск через терминал

```bash
cd ~/Downloads/FiberModeler
python3 serve.py
```

Или с GitHub:

```bash
cd ~/Documents
git clone https://github.com/NeoBlau/FiberModeler.git
cd FiberModeler
python3 serve.py
```

Остановить — `Ctrl+C`.

### 3.4. Ярлык в Dock

Перетащите `FiberModeler.command` на правую часть Dock (рядом с Корзиной).

## Проверка и пересборка (необязательно)

Нужен Node.js 18+ — только для тестов и пересборки одного файла. Сама программа работает без него.

```bash
node tests/run.js                   # 103 теста, без зависимостей
node tests/run.js weg               # только тесты библиотеки WEG
python3 tools/build_single_file.py  # пересобрать dist/FiberModeler.html
python3 tools/subset_font.py        # пересобрать встроенный шрифт для PDF
```

На Windows — то же самое, но `py` вместо `python3`:

```cmd
node tests\run.js
py tools\build_single_file.py
```

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| `python3: command not found` (Win: `py не является внутренней командой`) | Python не установлен или не добавлен в PATH. См. п. 2.1. Либо откройте `dist/FiberModeler.html` — он не требует Python |
| `OSError: [Errno 48] Address already in use` | Порт 8765 занят другой программой. Запустите `python3 serve.py --port 9000` |
| Браузер не открылся сам | Откройте вручную `http://127.0.0.1:8765` |
| Пустая белая страница | Вы открыли `index.html` напрямую, минуя сервер. Браузеры не дают ES-модулям работать с `file://`. Запустите через `serve.py` или используйте `dist/FiberModeler.html` |
| Windows: окно консоли мигнуло и закрылось | Запустите `FiberModeler.bat` из командной строки, чтобы увидеть сообщение об ошибке: `cd` в папку, затем `FiberModeler.bat` |
| macOS: «не удаётся проверить разработчика» | Правый клик по файлу → «Открыть» → «Открыть» |
| Папок WEG и Uber Eats нет в дереве | **Файл → Открыть библиотеки процессов** |
| Схемы на английском, а нужен русский | Иконка глобуса в правом верхнем углу, или **Настройки → Язык**. Библиотека перестроится на выбранном языке |

## Требования

| | Минимум |
|---|---|
| Python | 3.8+ — только для локального сервера; для `dist/FiberModeler.html` не нужен |
| Браузер | Safari 16.4+, Chrome 111+, Edge 111+, Firefox 113+ |
| Node.js | 18+ — только для тестов и пересборки |
| Место на диске | ~3 МБ весь проект, ~1 МБ один файл |
| Права администратора | не нужны |
| Интернет | не нужен после скачивания |
