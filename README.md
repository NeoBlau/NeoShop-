# 3DSFERA

Трёхмерная витрина, где товар показывают в действии до покупки: антенна
разворачивается, робот-пылесос едет по комнате, кресло раскладывается. Дальше —
заказ и физическая доставка. Вторая половина продукта — кабинет поставщика, где
производитель сам загружает GLB, настраивает анимации и выставляет товар в свой
павильон без участия нашей команды.

## Запуск

```bash
make dev
```

Одна команда: создаёт `.env`, ставит зависимости, поднимает Postgres, MinIO и
Mailpit в докере, применяет миграции, заливает демоданные и запускает API вместе
с веб-приложением.

| Что             | Где                   |
| --------------- | --------------------- |
| Веб-приложение  | http://localhost:5173 |
| API             | http://localhost:4000 |
| Почта (Mailpit) | http://localhost:8025 |
| MinIO console   | http://localhost:9001 |
| Prisma Studio   | `make db-studio`      |

Требования: Node 22+, pnpm 10+, Docker с плагином compose. Для десктопной
сборки дополнительно нужен Rust — но она понадобится только на шестом этапе.

## Команды

```bash
make help        # список целей
make up          # только инфраструктура
make app         # только приложение (api + web)
make db-dev      # создать миграцию из изменений схемы
make db-reset    # снести базу, накатить миграции, засеять заново
make seed        # демоданные
make test        # юнит-тесты (Vitest)
make e2e         # сквозные тесты (Playwright)
make lint        # ESLint
make typecheck   # tsc --noEmit по всем пакетам
make desktop     # Tauri-оболочка (этап 6)
```

## Структура

```
apps/
  api/        Fastify + Prisma. Бизнес-логика в src/modules/*/service.ts,
              HTTP — только транспорт
  web/        Vite + React. Логика в src/features/*, компоненты тонкие
  desktop/    Tauri-оболочка над той же веб-сборкой, своего 3D-кода нет
packages/
  shared/     zod-схемы, DTO, словари ru/en, контракт ошибок —
              один источник правды для фронта и бэка
docker/       инициализация MinIO
docs/         архитектура и руководство поставщика
```
