# Буран-М: Одиссея

Научный космический симулятор на Three.js / WebGL2. Вы управляете модернизированным
орбитальным кораблём «Буран-М»: выходите на орбиту, входите в атмосферу, садитесь на
планеты и спутники Солнечной системы, собираете научные данные, а потом прыгаете на
варп-двигателе к процедурно сгенерированным звёздным системам с экзопланетами.

## Запуск

Нужен [Node.js](https://nodejs.org) 18+ (LTS) и браузер с WebGL2.

**Одним щелчком:**

| Система | Файл                                                                                 |
| ------- | ------------------------------------------------------------------------------------ |
| Windows | `start-windows.bat` — двойной щелчок                                                 |
| macOS   | `start-macos.command` — двойной щелчок (при первом запуске: правый клик → «Открыть») |
| Linux   | `./start-linux.sh`                                                                   |

Лаунчер при первом запуске скачивает текстуры и three.js (≈30 МБ, дальше игра
работает без интернета), поднимает локальный сервер на свободном порту и
открывает игру в браузере. Окно терминала не закрывайте, пока играете.

**Вручную:**

```bash
cd apps/buran-odyssey
node tools/fetch-assets.mjs    # один раз, для офлайна (необязательно)
node tools/serve.mjs           # http://localhost:8080
```

Открыть `index.html` двойным щелчком нельзя: ES-модулям и Web Worker'ам нужен
http. Без `fetch-assets` игра берёт ресурсы из CDN (jsDelivr, запасной —
raw.githubusercontent).

Нужен браузер с WebGL2 (Chrome, Edge, Firefox, Safari 15+). На 4K-мониторе
выберите в меню качество «Ультра (4K)»: рендер идёт в нативном разрешении с
4× MSAA, bloom и картой теней 4096².

Самопроверка физики без рендера: `pnpm --filter @3dsfera/buran-odyssey test`.
Она проверяет кеплеровский пропагатор и дрейф энергии на орбите, пиковый нагрев и
перегрузку при входе в атмосферу Земли, стоянку и разбег на полосе Байконура, а
также пределы прочности шасси.

## Что внутри

### Физика (`src/physics`)

- **Гравитация.** F = G·M·m/r² от доминирующего тела, модель patched conics:
  опорное тело меняется на границе сферы действия Лапласа, r = a·(m/M)^0,4.
- **Интегратор.** Полуявный (симплектический) Эйлер с фиксированным шагом
  1/240 с. Он не зависит от частоты кадров: физика крутится в аккумуляторе, рендер
  просто рисует последнее состояние. При ускорении времени больше ×4 корабль
  идёт «по рельсам»: точное решение задачи двух тел в универсальных переменных
  (Vallado, алг. 8), с проверкой смены сферы действия и автоматическим сбросом
  ускорения перед атмосферой.
- **Эфемериды.** Кеплеровы элементы JPL (Standish, 1800–2050), Земля смещена от
  барицентра Земля–Луна. Средние элементы Луны, галилеевых спутников и Титана.
  Оси вращения и нулевые меридианы по IAU WGCCRE 2015.
- **Атмосферы.** Плотность ρ(h) гидростатическая: ρ₀ = P₀M/(RT₀), H = RT/(Mg).
  Для Земли используется кусочно-экспоненциальная таблица Vallado 8-4. Давление,
  температура, скорость звука и число Маха считаются из той же модели.
- **Аэродинамика.** Лобовое сопротивление Fd = ½ρv²·Cd·S и подъёмная сила. На
  дозвуке это линейная подъёмная сила дельта-крыла с полярой CD = CD0 + k·CL²
  (аэродинамическое качество около 5,6, как у «Бурана»). В гиперзвуке —
  модифицированная ньютоновская теория (Cp = 1,84·sin²θ), между ними волновой
  кризис. Fly-by-wire задаёт угол атаки: около 38° при входе и 6° на посадке.
- **Нагрев.** Конвективный поток по Саттону–Грейвсу, q = k·√(ρ/Rₙ)·v³, для
  N₂/O₂, CO₂ и H₂/He. Тепловой баланс поверхности ТЗП: поток минус излучение
  εσ(T⁴ − T∞⁴) плюс нагрев от звезды. Выше 1920 K RCC начинает разрушаться.
  Кабина прогревается от окружающей среды: на поверхности Венеры время жизни
  электроники ограничено, как у «Венеры-13».
- **Посадка.** Три стойки шасси с пружинно-демпферной моделью, свободное качение
  колёс и боковое сцепление, тормоза, руление носовой стойкой. Есть точки касания
  корпуса: удар брюхом или ТЗП разрушает корабль. Предусмотрены тормозные
  парашюты (рвутся выше 140 м/с), приводнение и раздавливание давлением в
  газовых гигантах.

Для сверки: вход с 120 км на 7,6 км/с в тесте даёт пик около 1750 K и 1,15 g.
Реальный «Буран» в 1988 году получил около 1,6 g и до 1900 K на носке.

### Вселенная (`src/world`, `src/data`)

- **Солнечная система.** Солнце, 8 планет, Плутон, Луна, Ио, Европа, Ганимед,
  Каллисто и Титан в реальном масштабе, с реальными периодами, наклонами осей и
  составами атмосфер.
- **Бесшовный переход от орбиты к поверхности.** Рельеф строится как
  кубосферное квадродерево: чанки 33×33 с юбками детализируются до вершин
  примерно через 1,6 м и генерируются в пуле Web Worker'ов. Координаты хранятся
  относительно центра чанка, а рендер идёт с плавающим началом координат в
  камере. Поэтому дрожания нет даже у Сатурна.
- **Реальный рельеф.** MOLA для Марса, LOLA для Луны, MLA для Меркурия,
  альтиметрия Magellan для Венеры, ETOPO для Земли, New Horizons для Плутона.
  Сверху добавлены аналитические ориентиры: гора Олимп (21,9 км, уступ, кальдера)
  и Долина Маринер (4000 км, глубина до 7 км). Мелкий масштаб дают популяция
  кратеров с распределением D⁻² и спектральный шум. Исторические места посадки
  сглажены, полоса «Юбилейный» выровнена.
- **Атмосферное рассеяние.** Однократное рассеяние Рэлея и Ми по лучу, с фазовой
  функцией Корнетта–Шэнкса, для каждого тела со своими коэффициентами: голубое
  небо Земли, рыжее Марса с голубым закатом, жёлтая мгла Венеры, оранжевая
  дымка Титана. Есть и воздушная перспектива на рельефе.
- **Экзопланеты.** Спектральные классы звёзд идут по локальной переписи (≈75% —
  M-карлики). Светимость L = 4πR²σT⁴, обитаемая зона по Копарапу (2013), линия
  льда 2,7·√L а.е., радиусы по соотношению Чена–Киппинга, парниковый эффект,
  приливный захват у M-карликов. Жизнь появляется только там, где возможна
  жидкая вода. Растения биолюминесцентные (три морфотипа, светящиеся споры),
  пигменты подстроены под спектр звезды: под M-карликом листва почти чёрная.

### Корабль (`src/ship`)

«Буран-М» собран параметрически по опубликованным размерам 11Ф35: длина
36,37 м, размах 23,92 м, двойная стреловидность крыла 78°/45°. У него работают
элевоны, расщепляемый руль-воздушный тормоз, балансировочный щиток, трёхстоечное
шасси и три тормозных парашюта. Вместо ДОМ стоит тройной плазменный двигатель:
1,6 МН, удельный импульс 3200 с. Теплозащита нарисована в 4K из собственной
геометрии корабля: чёрные HRSI-плитки с глазурью, белые LRSI, войлок на створках
отсека, RCC на носке и кромках, с разнотоном плиток, как у настоящего «Бурана».
К ней прилагаются карты нормалей, шероховатости и эмиссии: брюхо светится при
входе в атмосферу. Отдельно работают плазменный факел с ударными ромбами в
атмосфере, импульсы ДО и плазменная оболочка на наветренной стороне.

### Интерфейс

На приборах: орбитальная и приземная скорость, высота над средним радиусом и
радиовысота, вертикальная скорость, апоцентр и перицентр (относительно экватора
тела), наклонение, период, перегрузка, температура корпуса и тепловой поток,
плотность и давление атмосферы, число Маха, скоростной напор, угол атаки, состав
атмосферы. Навшар показывает векторы прогрейда, радиали, нормали, цели и места
посадки. В режиме карты видны конические сечения орбит, апсиды, сближение с целью
и параметры гомановского перелёта с фазовым углом. На звёздной карте — 14 звёзд
окрестностей.

## Честные ограничения

- Готовой 3D-модели «Бурана» с открытой лицензией в публичных CDN нет. Поэтому
  корабль построен процедурно из реальных размеров и затекстурирован в 4K.
  Базовых примитивов без текстур в игре нет.
- Для Каллисто и Титана нет глобальных цветных мозаик с CDN-совместимой
  лицензией. Их поверхность генерируется по описанию миссий Galileo и Cassini:
  насыщенность кратерами, дюны и метановые моря.
- Карты высот имеют разрешение 1–4K. Детали мельче пикселя карты
  (5–20 км/пиксель) синтезируются, но крупные формы — вулканы, бассейны,
  каньоны, моря — реальные.
- Гравитация учитывает одно тело (patched conics): так устроены KSP и
  большинство симуляторов. Приливных возмущений и точек Лагранжа нет.
- Плазменный двигатель и варп-двигатель — вымысел, остальная физика реальна.

## Управление

| Клавиши             | Действие                                                                            |
| ------------------- | ----------------------------------------------------------------------------------- |
| W / S, A / D, Q / E | тангаж, рыскание, крен                                                              |
| Shift / Ctrl, Z / X | тяга +/−, полная / отсечка                                                          |
| T, 1…8              | SAS, режимы: удержание, прогрейд, ретрогрейд, нормаль, антинормаль, радиаль ±, цель |
| R, H N J L I K      | ДО вкл/выкл, трансляция                                                             |
